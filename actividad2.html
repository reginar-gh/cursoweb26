Explicando un código de C e html


        #include 
        int main() {
            int edad;
            printf("¿Cuántos años tienes? ");
            scanf("%d", &edad);
            
            if (edad >= 18) {
                printf("Eres mayor de edad.\n");
            } else {
                printf("Eres menor de edad.\n");
            }
            return 0;
        }

el #include te permite hacer referencias a bibliotecas, en este caso a stdio.h
stdio.h es la biblioteca estándar de entrada/salida, por sus siglas en inglés


la función main es el punto de entrada del programa, es decir, el código que se ejecuta al iniciar el programa


la función printf se utiliza para imprimir texto en la consola
, en este caso para preguntar al usuario su edad y para mostrar si es mayor o menor de edad


la función scanf se utiliza para leer la entrada del usuario, en este caso la edad


el if es una estructura de control que permite ejecutar un bloque de código
si se cumple una condicion, en este caso si la edad es mayor o igual a 18 años

finalmente las salidas del if (verdadero o falso) indican, segun la respuesta recibida
si el usuario es mayor o menor de edad
